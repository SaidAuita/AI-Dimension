# Project Status

## Project
AI Dimension

## Path
C:\_CODE\illustrator\AI Dimension

## Purpose
Панель расширения (Adobe CEP) для Adobe Illustrator CC 2014-2026+ для автоматического нанесения размерных линий, габаритных стрелок, выносок зазоров между объектами, радиусов и диаметров окружностей в 4 квадрантах с поддержкой чертёжных стандартов (ГОСТ / ISO).

## Current Version
1.4.1

## Current Development State
Стабильный релиз. Продукт функционально полон, протестирован на Windows и macOS (включая Apple Silicon).

## Current Task
Поддержка стабильности, совместимость с новыми версиями Illustrator 2026. Активная разработка новых крупных фич не ведется (Maintenance Mode).

## Completed Features
- **Габаритные размеры**: автоматическая простановка ширины и высоты выделенных векторных объектов.
- **Измерение зазоров (Gap Measurement)**: измерение расстояния по 4 направлениям (горизонталь верх/низ, вертикаль лево/право) между двумя объектами.
- **Радиусы и диаметры**: простановка радиуса (R) и диаметра (O) в 4 квадрантах с горизонтальными посадочными полками.
- **Управление стрелками (Arrow ON/OFF)**: чекбокс включения/выключения стрелок, а также автоматическое отключение стрелок при установке значения 0 или пустом поле.
- **Поддержка масштаба чертежа (scale)**: масштабирование значений (1:10, 1:50, 1:100, 10:1 и произвольные множители).
- **Поиск шрифтов (Searchable Font Picker)**: выбор шрифта прямо в панели с нечётким поиском и кэшированием.
- **Единицы измерения**: мм, см, дюймы, пункты, пиксели с авто-адаптацией математики.
- **Цветовые пресеты**: 6 слотов CMYK-палитр для размерных линий и текста.

## Known Problems
- В очень больших файлах с тысячами шрифтов первичная инициализация списка шрифтов может занимать до 2-3 секунд (кэшируется после первого запуска).

## Important Technical Decisions
- Полный переписанный преемник старого скрипта *"AI measurment"*.
- Разделение UI на современный HTML/CSS интерфейс и высокопроизводительный ExtendScript для работы с геометрией кривых Безье.

## Important Files
- index.html — разметка панели, выбор режимов простановки размеров.
- CSXS/manifest.xml — манифест расширения CEP.
- js/main.js — клиентская логика интерфейса.
- js/fontPicker.js — модуль быстрого поиска и выбора шрифтов.
- js/dimensions.js — ExtendScript модуль создания размерных линий и стрелок в Illustrator.
- README.md — подробная документация на английском и русском языках.
