========================================================================
             AI DIMENSION v1.2 INSTALLATION GUIDE
========================================================================
[Scroll down for Russian / Инструкция на русском языке ниже]

The plugin supports Adobe Illustrator versions CC 2014 – 2026+ on Windows and macOS.

------------------------------------------------------------------------
WINDOWS INSTALLATION
------------------------------------------------------------------------
STEP 1: Enable Debug Mode (PlayerDebugMode)
1. Run the `enable_player_debug_mode.reg` file by double-clicking it.
2. Confirm adding the changes to the registry by clicking "Yes" -> "OK".

STEP 2: Copy the Extension Files
1. Press Win + R
2. Paste the path: %APPDATA%\Adobe\CEP\extensions
3. Press Enter, and copy the `AI Dimension` folder into the opened directory.

STEP 3: Launch in Adobe Illustrator
1. Restart Adobe Illustrator.
2. Open: Window -> Extensions -> AI Dimension (or Extensions (Legacy)).

------------------------------------------------------------------------
macOS INSTALLATION
------------------------------------------------------------------------
STEP 1: Enable Debug Mode
Open Terminal and execute the following command:
defaults write com.adobe.CSXS.9 PlayerDebugMode 1; defaults write com.adobe.CSXS.10 PlayerDebugMode 1; defaults write com.adobe.CSXS.11 PlayerDebugMode 1; defaults write com.adobe.CSXS.12 PlayerDebugMode 1; defaults write com.adobe.CSXS.13 PlayerDebugMode 1; defaults write com.adobe.CSXS.14 PlayerDebugMode 1; defaults write com.adobe.CSXS.15 PlayerDebugMode 1; defaults write com.adobe.CSXS.16 PlayerDebugMode 1

STEP 2: Copy the Extension Files
1. In Finder, press Cmd + Shift + G
2. Paste the path: ~/Library/Application Support/Adobe/CEP/extensions/
3. Copy the `AI Dimension` folder there (create the extensions directory if it does not exist).

STEP 3: Launch in Adobe Illustrator
1. Restart Adobe Illustrator.
2. Open: Window -> Extensions -> AI Dimension (or Extensions (Legacy)).

========================================================================
           ИНСТРУКЦИЯ ПО УСТАНОВКЕ AI DIMENSION v1.2
========================================================================

Поддерживаются версии Adobe Illustrator CC 2014 – 2026+ на Windows и macOS.

------------------------------------------------------------------------
УСТАНОВКА НА WINDOWS
------------------------------------------------------------------------
ШАГ 1: Включение режима отладки
1. Запустите файл `enable_player_debug_mode.reg` двойным кликом.
2. Подтвердите добавление изменений в реестр.

ШАГ 2: Копирование файлов
1. Нажмите Win + R
2. Вставьте путь: %APPDATA%\Adobe\CEP\extensions
3. Скопируйте папку `AI Dimension` в открывшуюся папку.

ШАГ 3: Запуск в Adobe Illustrator
1. Перезапустите Adobe Illustrator.
2. Откройте: Окно -> Расширения -> AI Dimension (или Расширения (устаревшие)).

------------------------------------------------------------------------
УСТАНОВКА НА macOS
------------------------------------------------------------------------
ШАГ 1: Включение режима отладки
Откройте программу "Терминал" (Terminal) и выполните:
defaults write com.adobe.CSXS.9 PlayerDebugMode 1; defaults write com.adobe.CSXS.10 PlayerDebugMode 1; defaults write com.adobe.CSXS.11 PlayerDebugMode 1; defaults write com.adobe.CSXS.12 PlayerDebugMode 1; defaults write com.adobe.CSXS.13 PlayerDebugMode 1; defaults write com.adobe.CSXS.14 PlayerDebugMode 1; defaults write com.adobe.CSXS.15 PlayerDebugMode 1; defaults write com.adobe.CSXS.16 PlayerDebugMode 1

ШАГ 2: Копирование файлов
1. В Finder нажмите Cmd + Shift + G
2. Вставьте путь: ~/Library/Application Support/Adobe/CEP/extensions/
3. Скопируйте папку `AI Dimension` туда.

ШАГ 3: Запуск в Adobe Illustrator
1. Перезапустите Adobe Illustrator.
2. Откройте: Окно -> Расширения -> AI Dimension (или Расширения (устаревшие)).
